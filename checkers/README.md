# Checkers App

This folder contains the standalone Swing Checkers application.

## Build

From the repository root:

```powershell
.\\mvnw.cmd -f .\\checkers\\pom.xml compile
```

## Run

From the repository root:

```powershell
.\\mvnw.cmd -f .\\checkers\\pom.xml exec:java
```

Or from this folder (if Maven is installed globally):

```powershell
mvn exec:java
```
